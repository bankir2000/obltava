ЗВЕДЕННЯ: ПАЛИВО ТА БК — PWA

Вміст: index.html, manifest.webmanifest, sw.js, папка icons/.
Усі файли мають лежати в одній папці (на хостингу — разом).

Розміщення (приклад, GitHub Pages):
1. Створіть репозиторій і завантажте ВСІ файли та папку icons у корінь (або в підпапку, наприклад /zvedennia/).
2. Увімкніть Settings -> Pages. Адреса буде https://<ім'я>.github.io/<репозиторій>/
3. Відкрийте адресу на телефоні:
   Android (Chrome): кнопка «Встановити» або меню ⋮ -> «Встановити додаток».
   iPhone/iPad (Safari): «Поділитися» -> «На початковий екран».
   Комп'ютер (Chrome/Edge): значок встановлення в адресному рядку.

PWA потребує HTTPS (GitHub Pages його дає). Подвійний клік по index.html теж працює, але без встановлення й офлайн-режиму.
Оновлення: замініть файли й підніміть V у sw.js (zvedennia-v1 -> v2).
